Version B：价格堆、可撤销FIFO队列与活跃订单索引

修改动机
A在每次提交时扫描整个活跃簿，匹配前排序所有合格maker，撤单也线性查找。
B用价格档位和直接ID索引减少这些工作。修改动机先于正式测量；现有实测结果见results/benchmark/FINDINGS.md。
A的实现文件和原有共享测试均保持不变。

数据结构
_orders：order_id -> 同一份活跃订单记录，供预检查重复ID及撤单定位。
_levels[side][price]：OrderedDict(order_id -> 记录)，插入顺序即FIFO。
价格队列和_orders是对同一记录的引用，订单只属于一个价格队列，不复制订单实体。
_heaps[side]：卖价正数最小堆，买价负数最小堆。
_heap_keys[side]：堆内键集合，含暂未清理的空档价格，用于防止重新挂价时重复入堆。
同价中间撤单用OrderedDict按ID删除，部分成交不移动队头。
无成交历史、历史订单ID或失效订单记录。

延迟清理规则
价格档变空后立即删除其队列，价格键可以暂留在堆中。
查询最优价时逐个弹出不在当前levels中的堆顶。
价格重新激活且旧键仍在堆中时复用旧键；它指向当前同价队列，不指向旧订单。
每次价格档变空后，若H > 2P + 64，则从当前有效价格重建堆与键集合。
其中H/P是该侧堆项数/活跃价格档数；若P=0则立即清空堆和键集合。
有效事件结束时每侧H <= 2P + 64，不会随历史事件总数无限积累价格键。
验证失败时不清理堆，保证拒绝事件不改变内部状态。

伪代码
validate：只读检查与A一致的字段/序号规则；活跃重复ID通过_orders查询。
cancel：_orders定位记录 -> 同价队列按ID删除 -> 若空则删除价格档并按阈值清理。
match：
    清理相反侧失效堆顶，读取最优价格
    若无价格或不满足限价边界则停止
    取同价队列最早maker，成交min(入单剩余, maker剩余)，按maker价格输出fill
    更新双方；maker耗尽时从队列和ID索引删除；价格档耗尽时触发上述清理
    重复直到入单耗尽或无可成交maker
    限价残量追加自身价格队列；必要时新建价格档并入堆；市价残量不挂单
inspect：只排序当前价格档，再按各队列FIFO复制记录，不清理或改变内部结构。

正确性不变量
每个活跃ID恰好在一个同侧价格队列中，且_orders指向该队列中的同一记录。
有效价格在堆中恰有一个键；最小堆在去掉空档堆顶后给出该侧最优价。
队列按到达顺序插入，部分成交原位减量，中间撤单不改变其他订单优先级。
每笔成交双方减少相同正整数，成交价格是maker价，残量规则与A一致。
清理只改变价格索引，不改订单量、价格、身份或到达序。
独立手算用例先在两版分别验证，再对随机流/供应数据逐事件比较输出和完整订单簿。
两版使用相同验证规则，故两版一致也不能替代独立预期测试。

时间复杂度（字典/集合/OrderedDict操作为期望常数；整数视作常数位宽）
B为活跃订单数，P为活跃价格档总数，F为本事件maker fills数。
S为本次最优价查询中弹出的失效价格键数，含本次刚耗尽的价格档。
R为本事件清空/重建堆和键集合的实际总工作量。
H为堆项数，受每侧2P+64阈值约束。以下log项写为log(P+65)避免小簿边界。

验证：期望O(1)，不扫描活跃订单。未知目标撤单：期望O(1)。
同价未成交挂单：若相反侧最优堆顶干净，期望O(1)；新建价格入堆O(log(P+65))。
一般限价单：期望O(1 + F + (S+I)log(P+65) + R)，I为新增价格键数(0或1)。
市价卖出：期望O(1 + F + S log(P+65) + R)。F包含fill列表构造和状态更新。
对一个事件可有许多历史失效价格键集中被清理，故不能把最优价查询笼统写成O(1)。
单事件最坏上界可写O(1 + F + (P_before+1)log(P_before+65))，受清理影响。

撤单定位和队列删除期望O(1)，但触发堆重建/整侧清空的单次撤单可达O(P_before+1)。
重建时失效键多于活跃键加64；重建成本可分摊给此前价格档删除，重建均摊期望O(1)/档删除。
堆顶弹出的log成本也需计入整体运行；每个堆键至多插入和弹出一次，重建为线性heapify。
用价格档创建次数C计，完整流可保守按期望O(M + sum(F) + C log(P_max+65))分析，
其中M含所有有效/拒绝事件，且包括清理费用；不能据此声称每次操作都有该最坏界。

查询：排序价格O(P log(P+1))，复制所有活跃记录O(B)，输出空间O(B)。
逻辑存储：O(B+P+64)，本事件返回fills另占O(F)，重建临时列表O(P)。
注意CPython字典/集合/OrderedDict可能保留曾经分配的容量，删除后不保证立刻归还内存；
实际容器容量与分配器缓存可能依赖历史峰值。上述逻辑记录界不等于实际tracemalloc字节，
也不等于进程RSS。后续内存实验须实测插入后和大量撤单后的状态。
