How to read these results

Each measurement covers one complete query batch, including sorting or set construction and the Boolean result list. Workload: mixed queries; hit rate 50.0%; unique input IDs (settings from the original benchmark; older CSVs lack these columns). Input generation and correctness checks are excluded. Results are medians of 5 repeats after one warm-up per method and input size.

Memory is measured in separate runs using Python's tracemalloc. It reports peak new traced allocations, including temporary data structures and results; it excludes the already-created inputs and does not represent total process memory. Timing and memory depend on the machine and Python version. Hover over chart points for values.
