Timing and memory

Times use the selected unit: s = seconds; ms = milliseconds; 1,000 ms = 1 s. The table and graph use the same unit, per complete batch of the selected query count. Memory is a separate tracemalloc run: current and peak traced Python allocations, with preparation and returned output included; pre-existing input and queries excluded. 1 KiB = 1024 bytes. These values are neither process RSS nor mathematical auxiliary space. Preparation, query and total are measured independently; their values need not add up.
