# AI Assistance Disclosure

AI assistance was used to propose the repository organization, synthetic-data
policies, test design, algorithm structure, measurement methodology, dashboard,
and documentation. The accepted suggestions include deterministic local random
number generators, within-range absent queries, shared parametrized tests,
separate preparation/query measurements, preservation of recursive and
iterative Binary Search versions, and saved-result dashboard inputs.

The design was corrected during collaboration to retain all 18 mandatory
configurations, report the actual singleton mixed hit rate, distinguish
mandatory and stress datasets, and preserve numerical file ordering without
breaking Python imports or pytest discovery.

No benchmark, memory, or test result is fabricated. Reported results originate
from executed scripts. AI-generated code remains subject to the automated tests
and reproducibility instructions documented in the repository.
